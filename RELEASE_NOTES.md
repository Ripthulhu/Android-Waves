# 0.4.6

First public Android release.

- Live wallpaper and screen saver with waves and sparkles.
- Seasonal, monthly, system and custom colours.
- A simpler settings menu and a colour picker.
- Home-screen scrolling and optional tilt response.
- Separate screen saver brightness for the background, waves and sparkles.
- Fixed the wave jump when tapping out of the screen saver on a locked phone.
- Fixed the sparkle burst after switching them off and back on.

Testing uses a Pixel 10 Pro XL running Android 17 for the wallpaper and screen
saver, and an Android 17 emulator for the new colour controls. Other phones and
launchers have not been tested. Exiting the screen saver without touching the
screen may still briefly show an old wallpaper frame.

Earlier test APKs used a different signing key. Uninstall those before installing
this release; doing so resets the app's settings.
